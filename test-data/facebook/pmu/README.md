# Athena Golden Dataset — Facebook / PMU

Use this folder for real Facebook group discussions that represent production usage.

Rules:
- Use real discussions only.
- Remove names, phone numbers, emails, profile links, screenshots, and private identifiers.
- Preserve the business meaning, objections, language, buyer intent, and thread structure.
- One discussion per `.txt` file.
- Use descriptive names:
  - career-change-001.txt
  - pricing-001.txt
  - certification-001.txt
  - client-acquisition-001.txt

These files are used to regression-test Athena's ingestion, analysis, opportunity detection, briefing generation, and Brain learning.
